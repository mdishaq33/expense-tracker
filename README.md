# Personal Expense Tracker

A command-line expense tracker built with Python and SQLite.

## Features
- Add and save expenses
- View recorded expenses
- Calculate total spending
- Export expenses to CSV

## Requirements
- Python 3.8 or later
- No third-party packages required

## Run the application

```bash
python main.py
```

## Export expenses

After adding expenses, run:

```bash
python export.py
```

This creates an `expenses.csv` file in the project folder.

## Storage
The application automatically creates an `expenses.db` SQLite database.
